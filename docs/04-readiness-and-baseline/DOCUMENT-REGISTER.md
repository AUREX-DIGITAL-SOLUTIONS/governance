All documents remain under founder-led interim stewardship until formal governance assigns accountable owners and review cycles. No document review date has yet been formally set.

## Update Rules

1. Update the relevant document before updating this register.
2. Record the document's new version and status here in the same change.
3. Assign a formal owner and review dates when the appropriate governance authority is established.
4. Use a Git tag for each approved institution-wide baseline release, beginning with `baseline-v1.0`.
5. Do not treat a draft version, repository change, or Git tag as legal incorporation, formal adoption, external authorization, or operational deployment.
